The repository contains an `app` module that depends on the `lib` module. It is currently a
minimal placeholder activity used to check that the library builds and installs in an
application.

Build and install it on a connected device or emulator:

[source,bash]
----
./gradlew :app:installDebug
----

https://github.com/albertoirurueta/irurueta-android-gl-cube[irurueta-android-gl-cube] (a
translucent 3D cube) and
https://github.com/albertoirurueta/irurueta-android-gl-curl[irurueta-android-gl-curl] (page curl
